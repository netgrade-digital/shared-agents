# OpenCode

Auto-configured by **`sa install`** when `~/.config/opencode` exists (or `./install.sh` from repo root).

Status: **`sa check`**

## Global instructions

`sa install` merges into `~/.config/opencode/AGENTS.md`.

## Sync

Agent runs `$SHARED_AGENTS_HOME/scripts/sync.sh pull` as first action each session.

## Skills

Symlinked to `~/.config/opencode/skills/` when present.
